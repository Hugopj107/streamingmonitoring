Tuning (applies to every region and ingest court)

Trigger threshold45%
% of a region's blocks that must change to fire. Player ≈ 2–8%; bars/slate/black ≈ 90–100%.
Block sensitivity18
Grey-level delta for a block to count as changed. Raise if crowd/shadows nudge it.
Grid density28 cols
Blocks per region across. 20–32 is a sweet spot.
Adapt speed0.04
How fast each reference drifts to absorb slow lighting/sun changes.
Flash hold1.5s
Minimum time a region's red border stays lit after firing.
No-signal timeout2.5s
Flag a region FROZEN if its picture stops changing for this long, or NO SIGNAL if it goes black — catches a stalled feed holding its last frame.
Freeze sensitivity20%
FROZEN fires when a feed's flicker drops below this fraction of its OWN normal level — it auto-calibrates per court, so a naturally clean camera and a noisy one both work. Lower = only flag a near-total freeze.
Alert latch0.6s
A fault must stay clear this long before the border releases. Raise it if alerts still flicker on/off; lower for snappier recovery.
Re-baseline CHANGE after8s
If a region stays in CHANGE this long it accepts the current picture as the new normal and clears — the safety net that stops it getting stuck (e.g. when you stop the feed). Only affects CHANGE; FROZEN / NO SIGNAL stay flagged as long as they're real.
